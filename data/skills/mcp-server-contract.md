Deliver an MCP stdio server with explicit tool schemas, initialize/list/call support, read-only safety for inspection tools, structured errors for bad arguments, README integration instructions, and tests that exercise each tool without requiring network or secrets. External API errors must remain failures, never simulated success. Require documented endpoints, explicit simulation, evidence-linked recommendations, approval for disruptive writes, and refreshed observations before claiming an action fixed an issue. Test authentication failure, timeouts and partial workflow failure with mocked HTTP.
