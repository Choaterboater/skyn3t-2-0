Open the README with a one-line description of what the app does, then a Quick Start assuming zero prior knowledge: clone, install dependencies, copy .env.example to .env and fill required values, and the single command to run it (plus the URL/port it serves). List prerequisites (runtime versions, Docker) explicitly and prefer one canonical run path, ideally docker compose up or a Makefile target like make run. Include how to run tests and a short Configuration section documenting key env vars. Validate by following your own steps from scratch; if it isn't up cleanly in ~10 minutes, the docs aren't done.
