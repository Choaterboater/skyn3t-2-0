For each eventual import, retain reviewed Markdown and required reference slices with their separate paths, immutable revision and license notices. Preserve those notices when deriving or redistributing material. Do not recursively ingest a whole prompt pack: the generic importer makes each Markdown file a separate skill and does not run bundled scripts ([skill_library.py:1044-1085](../../skyn3t/intelligence/skill_library.py#L1044-L1085), [curated provenance](../../skyn3t/intelligence/skill_library.py#L1103-L1110)).
